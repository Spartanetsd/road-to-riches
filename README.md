# Шлях до багатства

Сюжетна економічна гра про гроші за мотивами ідей книги «Найбагатша людина у Вавилоні». Ти — молодий ремісник у стародавньому Вавилоні: заробляєш 100 монет на місяць, віддаєш 70 за дах і хліб, а 60 винен лихвареві. Мета — побудувати **міцне господарство**: без боргів, із резервом на шість місяців і пасивним доходом, що покриває витрати цілий рік.

Гра — один файл `index.html`. Працює офлайн, без реклами й бібліотек, зберігається автоматично на пристрої. Зроблена для телефона (вертикальний екран), але відкривається і на комп'ютері.

## Як грати

Один хід — один місяць (2–4 хвилини):

1. **Дохід.** Ремесло, прибуток майстерні, дохід від вкладень.
2. **Бюджет.** Розкладаєш монети по чотирьох гаманцях: накопичення, необхідне, борг, на руках. Аркад радить залишати собі не менше десятої частини.
3. **Справа.** Одна на місяць: велике замовлення, навчання в майстра, відпочинок. Покупки (інструмент, майстерня, дім, скриня) та угоди справи не займають.
4. **Подія.** Зламаний інструмент, свято Мардука, повінь, замовлення з палацу, лихвар із позикою. Обираєш, як відповісти.
5. **Підсумок.** Куди пішли гроші й чого ти навчився.

Три професії — столяр, гончар, ткач — із різними особливостями. П'ять етапів: Порожній гаманець → Перші десять монет → Золото починає працювати → Випробування достатком → Міцне господарство. Сім «ліків від тонкого гаманця» відкриваються як досягнення.

## Механіки

- **Гаманець на руках** — готівка на інструменти, навчання й бажання. Те, що лежить у гаманці, потроху розходиться на дрібниці (15 % щомісяця, зі скринею — 5 %).
- **Накопичення** — захищені гроші. З них платять за майстерню, дім і угоди.
- **Борг** росте на 2 % щомісяця; мінімальний платіж — 5 монет.
- **Майстерня**: виручка показується окремо від прибутку (матеріали, оренда, платня помічникам).
- **Угоди** мають ціну, дохід, ризик і строк. За 5 монет можна перевірити партнера, його борги, попит і можливі втрати. Серед угод є пастка.
- **Сили й радість** впливають на дохід: великі замовлення виснажують, бажання додають радості, але коштують грошей.
- **Поразка**: три місяці поспіль позичати на необхідне або борг понад 300 монет. Після поразки можна відновитися.

## Викладання на GitHub Pages

1. Створи репозиторій і завантаж `index.html` та `README.md` (Add file → Upload files).
2. Settings → Pages → Source: *Deploy from a branch*, гілка `main`, папка `/ (root)`.
3. За хвилину гра буде за адресою `https://<логін>.github.io/<репозиторій>/`.

На телефоні сторінку можна додати на головний екран — гра працюватиме як застосунок, офлайн.

## Про гру

Оригінальна гра за мотивами ідей Джорджа Клейсона. Усі персонажі, угоди й цифри вигадані для гри. Ілюстрації створені автором спеціально для гри.
